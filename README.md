# Сайт кофейни RUMA — источник кофе

Минималистичный одностраничный сайт в фирменном стиле печатного меню.

## Структура

```
ruma-site/
├── index.html      — страница целиком (шапка, меню, отзывы, контакты)
├── css/style.css   — все стили; фирменные цвета заданы переменными вверху файла
├── js/menu.js      — ДАННЫЕ МЕНЮ: чтобы изменить цены или добавить позиции, правьте только этот файл
├── js/main.js      — рендер меню и переключение вкладок
└── img/            — логотип (кремовый и терракотовый), водяной знак, фавикон
```

## Фирменный стиль (взят из макета меню)

| Цвет | HEX |
|---|---|
| Терракотовый | `#935333` |
| Кремовый | `#EEE1CF` |
| Бежевый (фоновые иллюстрации) | `#E1CEB8` |

Шрифт: **Comfortaa** (Google Fonts) — округлый, максимально близкий к шрифту печатного меню.

## Как обновить меню

Откройте `js/menu.js` и отредактируйте список. Каждая позиция:

```js
{ name: "Латте", note: "300 мл", desc: "состав (необязательно)", price: "260" }
```

Новая категория — просто новый блок `{ title: "...", items: [...] }` в разделе
`drinks` (Напитки) или `food` (Завтраки и кухня).

## Как посмотреть локально

```bash
cd ruma-site
python3 -m http.server 8734
# открыть http://localhost:8734
```

Хостинг: папку можно выложить как есть на любой статический хостинг
(GitHub Pages, Netlify, Vercel, reg.ru и т.п.) — сборка не нужна.
