# Сайт кофейни RUMA — источник кофе

Минималистичный одностраничный сайт в фирменном стиле печатного меню.

## Структура

```
ruma-site/
├── index.html      — главная: шапка, герой, о нас, подборка меню, отзывы, контакты
├── menu.html       — полное меню с липкими вкладками и категориями
├── rolls.html      — переход со старых ссылок во вкладку «Роллы» общего меню
├── css/style.css   — все стили; цвета, шрифты и размеры заданы переменными вверху файла
├── js/menu.js      — ДАННЫЕ МЕНЮ: цены и позиции правим только здесь
├── js/ui.js        — общие помощники: варианты цен, строка меню, вкладки, часы работы
├── js/cart.js      — корзина, окна заказа, отправка в WhatsApp (подключается на обеих страницах)
├── js/main.js      — главная: подборка меню со свайпом, карусель отзывов
├── js/menu-page.js — страница полного меню
├── js/rolls.js     — карточки роллов с фото и окно блюда (состав, вес, кнопка «В заказ»)
├── scripts/bump-version.sh — обновляет ?v= у css/js одной командой
└── img/            — логотипы (полный, надпись RUMA, кремовый, водяной знак), фото героя, превью для соцсетей
```

## Фирменный стиль

Цвета взяты с логотипа: терракота `#804228` и кремовый `#E9DBC6`. Фон — тёплый крем,
заголовки и кнопки — терракота, текст — тёмный кофейный. Все значения — в блоке `:root` в начале `css/style.css`.

Шрифты (Google Fonts): **Playfair Display** — крупные заголовки, **Manrope** — основной текст, названия и описания блюд.

## Роллы

Роллы — третья вкладка общего меню (`MENU.rolls` в `js/menu.js`): подборка из четырёх на главной и все позиции на `menu.html#rolls`. Карточки сохраняют фотографии, состав и окно блюда. Старые ссылки `rolls.html` и `index.html#rolls` продолжают работать.
Каждая позиция:

```js
{ name: "Ролл Рума", price: "590", photo: "ruma", featured: 1,
  desc: "Рис, нори, лосось …" }   // состав: и на карточке, и в окне блюда (граммовку на сайт не выносим)
```

Фото лежат в `img/rolls/`: `<photo>.webp` (общий план) и `<photo>-detail.webp` (крупный план, он проявляется при наведении
и вторым кадром в окне блюда). Размер 1000×1250, формат WebP.
Новый ролл: добавьте две фотографии и позицию в список. `featured: 1…4` — порядок на главной.

## Навигация на телефоне

На экранах до 760px верхнее меню заменено нижней панелью «Liquid Glass» (`js/ui.js`, `setupTabbar`; стили — блок «нижняя панель» в `css/style.css`):
Главная · О нас · Меню · Контакты. Кнопка «Меню» ведёт в общий каталог с тремя вкладками. Активный раздел подсвечивается каплей стекла, на главной — по прокрутке.
Пункты панели собираются в `setupTabbar`; на каждой странице в `<body>` задан `data-page`.

## Оплата и сохранение заказа

- Для такси обязательны адрес и способ оплаты.
- Товары сохраняются без адреса и комментария. При загрузке их цены сверяются с текущим меню.
- Постоянный `id` позиции в `js/menu.js` сохраняйте при изменении цены, имени и порядка. Для новой позиции задавайте новый уникальный ID.
- Адрес, время самовывоза и комментарий хранятся отдельно в этой вкладке до 30 минут.
- «Очистить всё» удаляет товары, детали и ожидание подтверждения.
- После перехода в WhatsApp сайт спрашивает, отправлен ли заказ. Подтверждение относится к конкретной версии корзины, новые позиции из другой вкладки сохраняются.
- Для одновременных изменений используется Web Locks в современных браузерах. В старых браузерах без Web Locks работает обновление между вкладками, однако одновременная запись может конфликтовать.

## Проверки перед публикацией

```bash
npm ci
npx playwright install chromium
npm test
```

Проверки используют отдельный браузер с перехватом запросов и вымышленными данными.
Проверяются миграция старой корзины, цены, очистка деталей, переключение получения,
одновременные вкладки, подтверждение, безопасные ссылки и переходы между страницами, три вкладки меню, фото роллов, историю переходов и узкие экраны.

## Установка на экран «Домой»

Сайт устанавливается как приложение: название **РУМА**, значок — логотип RUMA (`manifest.webmanifest`, `img/icons/`).
В манифесте задана область `scope: "./"`, поэтому все страницы (меню, роллы) открываются внутри приложения, а не во внешней вкладке.
В установленном приложении отключено масштабирование щипком и двойным касанием (`js/app-shell.js`); в обычном браузере
щипок для увеличения работает, двойное касание не увеличивает (`touch-action: manipulation`).

## Заказ через WhatsApp

У каждой позиции меню есть кнопка «+». Собранная корзина отправляется
готовым сообщением в WhatsApp на номер кофейни. Гость выбирает формат:
«С собой», «На месте», «Заберу заказ» (с полем времени) или
«Отправить на такси» (с полем адреса). Есть поле комментария к заказу
и кнопка «Очистить всё»; выбранное количество видно на кнопках «+»
прямо в меню.

Номер для приёма заказов задан константой `WHATSAPP_PHONE` в начале
`js/cart.js` — при смене номера поменяйте только её.

Позиции с двумя ценами (например, «Капучино 200/300 мл — 260/280»)
автоматически предлагают выбор объёма. Корзина сохраняется при
перезагрузке страницы (localStorage).

## Как обновить меню

Откройте `js/menu.js` и отредактируйте список. Каждая позиция:

```js
{ name: "Латте", note: "300 мл", desc: "состав (необязательно)", price: "260" }
```

Вкладки сайта: `drinks` — «Кофе и напитки», `food` — «Завтраки и кухня», `rolls` — «Роллы».
Чтобы позиция попала в подборку на главной, добавьте `featured: 1` (число — порядок показа).
Время завтраков в «Контактах» берётся из пометки категории «Завтраки» (`note`).
Пометка рядом с названием — `badge: "хит"`.

Новая категория — просто новый блок `{ title: "...", items: [...] }` в разделе
`drinks` (Напитки) или `food` (Завтраки и кухня).

После правок в `menu.js`, `style.css` или JS-файлах запустите:

```bash
./scripts/bump-version.sh
```

Скрипт проставит новую версию `?v=` у всех подключаемых файлов во всех HTML-страницах,
иначе браузер гостя может до 10 минут показывать старую версию из кеша.

## Часы работы

Заданы в `js/ui.js`, переменная `HOURS` в начале файла (считаются по московскому времени,
`TIMEZONE`). Строку «Ежедневно 07:30–23:00» продублируйте вручную в `index.html` в разделе
«Контакты» и в данных для поисковиков (JSON-LD) в `<head>` (`opens`/`closes`). Бейдж «Открыто/Закрыто»
на сайте считается автоматически.
