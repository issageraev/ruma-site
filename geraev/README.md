# Личное портфолио — Исса Гераев / GERAEV TECHNOLOGY

Минималистичный одностраничный сайт-портфолио. MVP: шапка с контактами,
«Обо мне», три кейса, контакты. Полностью независим от сайта РУМА в
корне этого репозитория — свои стили, скрипты и картинки, ничего общего.

## Структура

```
geraev/
├── index.html            — страница целиком (шапка, обо мне, кейсы, контакты)
├── css/style.css          — все стили; токены заданы переменными вверху файла
├── js/i18n.js              — ДАННЫЕ ПЕРЕВОДА: RU/EN словарь, чтобы изменить текст — правьте только этот файл
├── js/main.js               — переключатель языка, контактные ссылки, анимация при скролле
└── img/
    ├── favicon.svg          — временная монограмма «G» (полноценный логотип — позже)
    ├── hero/                 — фото в шапке
    ├── about/                — фото в разделе «Обо мне»
    └── cases/ruma/           — скриншот сайта РУМА для кейса
```

## Стиль

| Токен | HEX |
|---|---|
| `--paper` (фон) | `#F6F3ED` |
| `--sand` (карточки/альт-секции) | `#DFD8C9` |
| `--ink` (текст/кнопки) | `#17140F` |
| `--ink-soft` (вторичный текст) | `#55503E` |

Шрифты: **Playfair Display** (заголовки) + **Inter** (текст/интерфейс),
Google Fonts, обе с поддержкой кириллицы.

## Контакты (WhatsApp / Telegram / почта)

Номер, юзернейм и почта заданы константами в начале `js/main.js`
(`WHATSAPP_PHONE`, `TELEGRAM_USERNAME`, `EMAIL`) — при смене меняйте только
их. Те же значения на всякий случай продублированы прямо в `href` кнопок в
`index.html`, чтобы кнопки работали, даже если JS не выполнился — при смене
контактов поправьте оба места.

## RU/EN переключатель

Весь текст на странице сразу на русском (в `index.html`) — так сайт
корректно читается и без JS. У переводимых элементов есть атрибут
`data-i18n="ключ"`, а сами переводы лежат в `js/i18n.js` (объект `I18N`,
секции `ru` и `en`).

Часть длинных блоков (текст «Обо мне», описания кейсов) на английском
сейчас — заглушка вида «English description coming soon». Чтобы добавить
настоящий перевод — впишите текст в `js/i18n.js` под тем же ключом в секции
`en`, разметку трогать не нужно. Пустая строка `""` у ключа автоматически
скрывает соответствующий элемент (так собраны пустые абзацы «Обо мне» —
на английском показывается один абзац-заглушка вместо пяти).

## Заглушки вместо недостающих фото

Три места промечены `<!-- TODO: ... -->` в `index.html` и оформлены как
`.media-placeholder` (пунктирная рамка, подпись «...— скоро»):
макет/фото NFC-карточки в кейсе РУМА, финальные макеты «Кофе с характером»,
фото продукта в кейсе NFC-визиток. Как появится материал — замените
`<div class="media-placeholder">...</div>` на `<img class="case-media" ...>`
по образцу скриншота РУМА в том же файле.

После правок в любом из файлов увеличьте `?v=` на 1 у соответствующего
`<link>`/`<script>` в `index.html` — иначе у гостя, который уже открывал
сайт, до обновления кеша может показываться старая версия.

## Как посмотреть локально

Открывать нужно **из корня всего репозитория ruma-site**, а не из
`geraev/` — так локальный просмотр повторяет то, как страницу отдаёт
GitHub Pages (сайт РУМА в `/`, портфолио в `/geraev/`), и сразу видно, если
где-то случайно использован абсолютный путь вместо относительного.

```bash
cd ruma-site
python3 -m http.server 8734
# открыть http://localhost:8734/geraev/
```

Хостинг: GitHub Pages, раздаёт репозиторий как есть — сборка не нужна.
После публикации портфолио будет доступно по адресу `.../ruma-site/geraev/`.
Перенос на отдельный домен/репозиторий в будущем — просто копирование
папки `geraev/` целиком, внутренние пути в ней все относительные.
